# 📢 학과 소통 & 불만 접수 게시판 (Complaint Board)

학과 구성원이 공지사항과 의견/불만 사항을 공유하고 소통할 수 있는 **React + Vite + Supabase** 기반 웹 게시판 애플리케이션입니다.

---

## 🔑 실험 및 과제용 로그인 계정 안내

웹사이트 접속 시 학과 외 외부인 차단을 위해 **로그인 게이트 화면이 가장 먼저 표시**됩니다.

- **실험/과제용 테스트 계정**:
  - **아이디 (ID)**: `abcd`
  - **비밀번호 (PW)**: `1234`
- 로그인 화면 상단의 **[이 계정으로 자동 입력하기]** 버튼을 누르시면 클릭 한 번으로 입력되어 바로 로그인할 수 있습니다.
- [신규 회원가입] 탭을 통해 직접 새로운 학과 구성원 계정을 생성하여 로그인할 수도 있습니다.
- 상단 헤더의 **[로그아웃]** 버튼을 누르면 언제든 로그인 화면으로 돌아갑니다.

## ⚡ 빠른 시작 (실행 방법)

교수님 또는 평가자가 프로젝트를 내려받아 실행할 때는 아래 단계를 순서대로 진행하시면 됩니다.

### 방법 1. 터미널 명령어로 실행하기
Node.js가 설치된 환경에서 저장소를 클론(또는 압축 해제)한 후 해당 폴더 터미널에서 다음 명령어를 순서대로 실행합니다:

```bash
# 1. 의존성 패키지 설치 (최초 1회 필수)
npm install

# 2. 로컬 개발 서버 실행 (자동으로 localhost:3000 구동)
npm run dev
```

서버 실행 후 브라우저 접속: 👉 **[http://localhost:3000](http://localhost:3000)**

---

### 방법 2. 윈도우 원클릭 배치파일로 실행하기 (Windows 전용)
프로젝트 폴더 내의 **`게시판_실행.bat`** 파일을 더블 클릭하시면 서버가 자동으로 실행되고 기본 웹 브라우저 창이 열립니다.  
*(※ 최초 실행 시 터미널에서 `npm install`이 한 번 실행되어 있어야 합니다)*

## ☁️ Vercel 무료 배포 안내 (웹 링크 제출 시)
GitHub 저장소 링크뿐만 아니라 **설치 없이 웹에서 바로 열리는 링크**가 필요하신 경우:
1. GitHub에 이 저장소를 Push합니다.
2. [Vercel](https://vercel.com)에 로그인 후 해당 레포지토리를 Import합니다.
3. 설정 변경 없이 **[Deploy]** 버튼만 누르면 1분 만에 `https://xxx.vercel.app` 형태의 배포 주소가 생성됩니다. (`vercel.json` 설정이 이미 포함되어 있습니다)
